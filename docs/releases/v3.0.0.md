## Monitor history and explicit profiles

- A new main window centered on **Storico monitor** and profiles.
- Persistent history includes disconnected monitors remembered by Windows. Rename screens once and use those names in every profile.
- Choose exactly which monitors to enable, the resolution of each and the primary monitor. Other screens are disabled; multiple enabled screens extend the desktop.
- The actual active profile is shown in the window, list and tray. An explicit deactivation action stops protection while keeping the current screen configuration.
- New profiles enable resolution protection: exact desktop modes, aspect-preserving scaling, verified output and automatic restoration of detected changes. Missing monitors pause protection; repeated conflicts suspend it to avoid continuous mode changes.
- Existing profiles and shortcuts are preserved. Old generic profiles need explicit monitor selection; protection for imported profiles remains opt-in. The old quick topology controls and two-profile switch are removed.

### Gaming limit
Use **Borderless / Finestra senza bordi** and the profile resolution in the game. Exclusive fullscreen can independently request modes or scaling. Protection restores detected Windows output changes; it cannot universally lock a game's internal rendering, field of view or exclusive-fullscreen behavior. GPU/monitor scaling support still matters. No driver or EDID override is installed.
