## Profile switching fix

- Fixed the generic "Windows ha applicato impostazioni diverse dal profilo salvato" error on Windows virtual-mode display paths, including Intel-driven ultrawide monitors.
- Set the requested desktop image explicitly, so a 1920 x 1080 profile does not inherit the previous ultrawide virtual desktop surface. Native physical signal timings remain available for GPU aspect scaling.
- Wait for the display change to settle before verification. Genuine resolution/aspect mismatches still trigger recovery and now include the requested and received settings in the error.
- Preserve virtual desktop geometry in recovery snapshots and verify both virtual image scaling and physical output scaling.

Existing profiles and monitor names are preserved; **you do not need to recreate your profiles**. Install from **Aggiornamenti** or download below.
