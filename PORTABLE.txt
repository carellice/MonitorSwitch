MonitorSwitch 3.0.1 - Windows 10/11 x64

Extract this package and run MonitorSwitch.exe. No installation, administrator
rights or additional runtime packages are required. The interface is Italian.

History lists monitor interfaces remembered by Windows, screens observed by
the app and displays in existing profiles, including disconnected monitors.
Use Rinomina to give a screen a name shared by all profiles. Last-seen times
are recorded by the app; historical Windows-only entries can have no date or
known resolution. Changing ports/docks/drivers can create a new device identity.

Choose Nuovo, name the profile, check the screens to enable and select or enter
the resolution of each. Choose the primary monitor. Unchecked screens turn off;
multiple selected screens extend the desktop horizontally. Save, then activate.
A disconnected screen must be reconnected before its profile can be applied.
The active profile is verified against actual output settings, not list focus.

New profiles enable resolution protection. Keep the app running in the tray:
it detects changes and checks every 1.5 seconds while a protected profile is
armed, restores the requested resolution and verifies aspect preservation.
No substituted resolution is accepted. A missing screen pauses protection.
Repeated conflicts suspend it after three corrections within one minute;
reactivate the profile after resolving the conflict. Disattiva profilo stops
protection without changing the screens. Closing the app keeps display settings
and stops protection. Restart only rearms a saved profile that still matches.

For games, use Borderless / Finestra senza bordi and the profile resolution.
Exclusive fullscreen can choose its own modes and scaling. This app reacts to
observed Windows output changes; it cannot universally lock a game's internal
rendering resolution, field of view or exclusive-fullscreen behavior. The GPU
must support aspect-preserving scaling. Monitor-side scaling is not controlled.
No driver, EDID override or game hooks are installed.

Manual changes have a 20-second rollback confirmation by default. A separate
recovery process protects unfinished changes. Automatic corrections use the
backup and verification without repeated confirmation prompts.

Existing 2.x profiles and shortcuts are preserved. Exact layouts remain usable;
old generic profiles marked Configura must be edited to select physical screens.
Legacy protection is off until enabled. Saving in the new editor creates an
extended layout. Quick topology buttons and the old two-profile switch are gone.

Avvia con Windows (minimizzato) optionally starts the app in the tray at sign-in.
Keep the portable EXE in a permanent location. Aggiornamenti checks GitHub and
offers a verified download and restart. Settings/history survive an update;
the previous EXE is kept with a .previous suffix. Startup checks are optional.
Binaries are unsigned. SHA256SUMS.txt is available with release downloads.

Settings, monitor names and history: %LOCALAPPDATA%\MonitorSwitch\profiles.xml
Pending recovery: %LOCALAPPDATA%\MonitorSwitch\pending-display.bin
Diagnostics: %LOCALAPPDATA%\MonitorSwitch\errors.log
Do not delete an unfinished recovery backup. Reconnect the original monitors
and reopen the app if recovery cannot complete. Review logs before sharing.

Requested modes require hardware/driver support. HDR, VRR, DPI, brightness and
color profiles are not managed. See README.md and LEGGIMI.txt for more details.
