MonitorSwitch 2.3 - Windows 10/11 x64

Extract the ZIP, then run MonitorSwitch.exe. No installation or administrator
rights are required. The app uses the .NET Framework included with Windows.

The default Game (Gioco) and Work (Lavoro) profiles switch between duplicated
screens and external displays only. You can rename profiles, choose other
display modes, save the current layout, and assign global keyboard shortcuts.

Click Modifica (Edit), enable Personalizza monitor e risoluzioni (Customize
monitors and resolutions), and select or type a resolution for each display.
Duplicated monitors share one desktop resolution. Extended displays can use
different resolutions.

Ctrl+Alt+F10 switches between the two profiles selected at the bottom.
Ctrl+Alt+F1 through F4 apply the four default profiles. All shortcuts can be
customized. Keyboard and tray-menu switches keep the main window in the tray.

Confirm changes within 20 seconds, or the previous configuration is restored.
After testing your profiles, uncheck Conferma dopo il cambio to switch with
one click. Minimize to keep shortcuts available. Closing the app keeps the
last confirmed display configuration active.

Profiles: %LOCALAPPDATA%\MonitorSwitch\profiles.xml
Errors: %LOCALAPPDATA%\MonitorSwitch\errors.log

START WITH WINDOWS
Enable Avvia con Windows (minimizzato) in the main window or tray menu.
At Windows sign-in the app starts hidden near the clock, with shortcuts ready.
Double-click the tray icon to open it. Disable the same option to remove startup.
No administrator rights are needed. No display profile is applied on startup.
Keep the EXE in a permanent location; after moving or renaming it, disable and
re-enable the option from the new location. If disabled in Windows Task Manager,
re-enable it there as well.

UPDATES
Open Aggiornamenti from the window or tray menu. If a newer stable GitHub
release exists, click Scarica e riavvia (Download and restart). Profiles are
preserved. The download is verified against GitHub's SHA-256 asset digest
and embedded executable version. The previous EXE is retained as .previous.
The application folder must be writable. Automatic startup checks can be
disabled from the tray menu; successful checks happen at most once per day.
Version 2.1.0 and earlier need a one-time manual download to gain this feature.
